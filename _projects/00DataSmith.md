<div class="content">
DataSmith is an attribute-driven data modeling framework for Unity that automatically generates strongly-typed models and fluent query APIs.

It delivers an ORM-like developer experience for in-memory gameplay data, enabling scalable, maintainable systems without boilerplate or runtime reflection.
</div>
<div class="content">
<h2># 🚀 Features</h2>

<ul class="highlight-list">
    <li>Attribute-driven model definitions</li>
    <li>Automatic code generation (Models + Queries)</li>
    <li>Strongly-typed accessors and events</li>
    <li>Fluent, lazy query system</li>
    <li>ORM-like developer experience</li>
    <li>Centralized data architecture</li>
    <li>Zero runtime reflection</li>
    <li>Designer-friendly workflow</li>
    <li>Scales to large projects</li>
</ul>
</div>
